Submission Reminder App

This shell-based application assists in finding out students that have not submitted their assignments.

Features

Establishes a systematized system of keeping track of submissions.
Relies on submissions.txt to keep student records.
Allows the name of assignment to be updated through copilot_shell_script.sh.
Sends notifications on start up.sh.

Setup

Run create_environment.sh and put your name as needed. It will generate a list of personalised directory containing all the required files.

Usage

Startup.sh to verify pending submissions.
Make changes with copilot_shell_script.sh to change assignment name to check the people that have not submitted the new assignment name.
